# Gesture2Visual – AI Sign Language Translator

## Overview

Gesture2Visual is an AI-powered communication system that recognizes sign language gestures in real time using Computer Vision and Artificial Intelligence. The system converts hand gestures into readable text and voice, enabling seamless communication for individuals with hearing and speech impairments.

## Features

- Real-time Sign Language Recognition
- Computer Vision-based Hand Tracking
- Text Generation
- Voice Output
- AI-powered Gesture Classification
- User-friendly Interface

## Technologies Used

- Python
- OpenCV
- MediaPipe
- Artificial Intelligence
- Deep Learning
- Text-to-Speech
