# Installation Guide

## Prerequisites

- Python 3.10 or above
- Webcam
- Git (Optional)

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Gesture2Visual-AI-Sign-Language-Translator.git
```

Navigate to the project folder:

```bash
cd Gesture2Visual-AI-Sign-Language-Translator
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```

## Expected Output

- Webcam opens automatically.
- Hand gestures are detected using MediaPipe.
- The predicted gesture is displayed on the screen.
- The detected gesture is converted to speech using Text-to-Speech.
