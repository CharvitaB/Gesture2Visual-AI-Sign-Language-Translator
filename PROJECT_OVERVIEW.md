# Project Overview

## Gesture2Visual – AI Sign Language Translator

Gesture2Visual is an AI-powered assistive communication system designed to bridge the communication gap between hearing/speech-impaired individuals and the general public. The application uses Computer Vision, MediaPipe, and Artificial Intelligence to recognize hand gestures in real time, classify sign language gestures, and convert them into readable text and audible speech.

The system captures live video through a webcam, extracts hand landmarks using MediaPipe, processes gesture features through an AI-based classifier, and generates voice output using Text-to-Speech technology. The project aims to improve accessibility, promote inclusive communication, and demonstrate the practical application of AI in assistive technology.

## Objectives

- Enable real-time sign language recognition.
- Convert gestures into text and speech.
- Improve communication accessibility.
- Demonstrate AI-driven human-computer interaction.
- Develop a low-cost and user-friendly assistive solution.

## Applications

- Assistive Technology
- Healthcare
- Educational Institutions
- Public Service Centers
- Smart Accessibility Solutions
